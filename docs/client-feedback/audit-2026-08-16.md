## Notas de medición (para no repetirlas)

- **`python3 -m http.server` no sirve acá**: el hostname de la máquina tiene un byte no-UTF8
  y `getfqdn()` explota. Hay que sobreescribir `server_bind`.
- **Y no uses `os.chdir` para la raíz**: si otra sesión rebuildea `dist/`, el proceso queda
  con un inodo muerto y `os.getcwd()` tira `FileNotFoundError` en cada request — el server
  sigue escuchando pero devuelve error. Pasar `directory=` explícito.
- **Un server de un solo hilo se cuelga** con Chrome. `ThreadingTCPServer`.
- **Al medir G6, `hero.querySelector('p')` agarra el BADGE, no el subline.** Con eso reporté
  spreads de 200–400px que no existían. Hay que apuntar a `.*__lead`.
- El harness CDP quedó en el scratchpad de la sesión (`cdp.py`, `serve.py`).
